Financial Chatbot Prototype

Description:
This project is a simple rule-based financial chatbot developed using Python.

Features:
- Answers predefined financial queries.
- Provides revenue, net income, and operating cash flow information.
- Compares financial performance among Microsoft, Apple, and Tesla.

Predefined Queries:
- Microsoft revenue
- Apple revenue
- Tesla revenue
- Microsoft net income
- Apple net income
- Tesla net income
- Best revenue
- Operating cash flow

Limitations:
- The chatbot only responds to predefined questions.
- It does not use Artificial Intelligence or Natural Language Processing.
- It cannot answer questions outside its predefined dataset.
